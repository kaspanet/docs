---
title: Transaction payload
description: Use the transaction payload field for application data within standard mempool limits.
---

With the high-level Wallet API, it is just another `accountsSend()` request field:

```js
await wallet.accountsSend({
  accountId: account.accountId,
  walletSecret,
  priorityFeeSompi: 0n,
  destination: [{ address: recipient, amount: kaspaToSompi("10") }],
  // arbitrary data can be attached to a transaction
  payload: new TextEncoder().encode("order:1337"),
});
```

For mempool acceptance, the overall estimated serialized transaction size is capped at `250 KB` (`250,000` bytes).

The exact payload ceiling is lower once the transaction also includes inputs, outputs, signatures, and other fields, because they all count toward the same serialized size. Compute mass, storage mass, and minimum relay fee checks also still apply.
